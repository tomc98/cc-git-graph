# Project status

The initial public version is **0.1.4 experimental**, not a completed 1.0. Browsing, repository mapping, comparisons, Git action previews/confirmation, selected-context handoff and multicolour rendering are implemented.

Public preparation includes an MIT licence, generic examples, user installation/update/removal instructions, contributor checks, a repository-root marketplace, a clean runtime package and a CI workflow. The existing local-development marketplace name remains available in `dist/`.

The README includes two framed illustrations adapted from supplied screenshots, with private repository details and conversation text replaced by fictional demo content. The public destination is [tomc98/cc-git-graph](https://github.com/tomc98/cc-git-graph); release assets and CI results are available through its Releases and Actions pages. Compatibility and acceptance gaps are listed in [COMPATIBILITY.md](COMPATIBILITY.md) and [QA.md](QA.md).

The original development logs are retained locally under ignored `work/public-prep/originals/`; they are excluded from public source and packages. No personal Claude profile is changed by packaging or these public-preparation steps.
