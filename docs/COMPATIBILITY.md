# Compatibility

## Tested target

| Component | Recorded environment |
| --- | --- |
| Plugin | 0.1.4 experimental candidate |
| Claude Code | Native 2.1.272, function hooks enabled |
| macOS | 26.5.2 |
| Git | 2.55.0; SHA-256 fixtures covered |
| Node | Development checks require 24+; initial checks used 26.8.2 |
| TypeScript | 5.9.3 |
| Python / clipboard | `/usr/bin/python3` / `/usr/bin/pbcopy` |

This is a tested target, not a minimum-version promise. The [upstream function-hook API](https://github.com/anthropics/claude-code/blob/v2.1.272/mods/README.md) is early access. Other builds need native verification.

## UI support

| Surface or behaviour | Evidence / limit |
| --- | --- |
| Terminal conversation, fullscreen | Native launcher, graph, commit selection and close tested through a dedicated PTY |
| 80 / 109 / 110 / 144 / 200 columns | Coloured graph captured at all five widths; mapped browsing and draft-preserving close tested |
| Wide fullscreen | Host-managed side pane begins at 110 terminal columns on the tested build |
| Narrow terminal | Inline panel; content and badges adapt to available width |
| Keyboard | Focus cycling, basic browsing and selected action flows tested; complete subview coverage remains open |
| Non-fullscreen | Keyboard open/switch/close tested; synthetic mouse activation did not pass |
| Built-in Diff | Covers Git Graph; closing Diff reveals it. No verified tabbed coexistence |
| Separate `claude agents` overview | Unsupported |
| Agent transcript / Ask Claude routing | Not certified; Ask Claude is offered only for the main conversation |
| Desktop, mobile, Linux, Windows | Not supported by this candidate |

PTY captures are evidence of native CLI behaviour, not a physical-terminal user acceptance session. Native background execution, queued handoff while streaming, every signing/editor configuration and all keyboard paths are not certified.

## Type contracts

Local host verification uses declarations generated by `/plugin-types` in the installed CLI. These stay ignored under `.claude/types/`.

Public CI independently downloads the declaration from Anthropic's `v2.1.272` tag into ignored `.cache/claude-types/`, verifies a pinned SHA-256, then typechecks with `tsconfig.ci.json`. That file's header says 2.1.271; it differs from the locally generated contract in built-in tool declarations. Passing against it is a reproducible static check, not a substitute for native testing on 2.1.272.

Neither declarations nor the Claude executable are redistributed in the plugin or release archive.
